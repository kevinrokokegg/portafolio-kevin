# Portafolio personal de Kevin Herrera

## Estudiante
Kevin Raúl Herrera Castro.

## Descripción
Portafolio personal desarrollado como proyecto académico para presentar
mi formación, habilidades y proyectos como estudiante de Ingeniería
en Sistemas Inteligentes y técnico superior en Redes y Telecomunicaciones.

Incluye: presentación, información sobre mí, habilidades, proyectos
y un formulario visual de contacto que no envía información.

## Tecnologías utilizadas
- HTML5 para estructurar el contenido.
- CSS3 para el diseño y la adaptación a diferentes tamaños de pantalla.
- Git para registrar el progreso mediante commits.
- GitHub para almacenar y compartir el proyecto.

## Cómo visualizar el proyecto
1. Descargar el repositorio desde Code > Download ZIP.
2. Extraer el archivo ZIP.
3. Abrir index.html en un navegador web.

Mantener styles.css y la carpeta img en sus ubicaciones originales
para que los estilos y las imágenes se carguen correctamente.

## Archivos del proyecto
- index.html: contenido principal del portafolio.
- styles.css: estilos del sitio.
- img/: fotografía personal e imagen del proyecto.
- README.md: descripción e instrucciones.
